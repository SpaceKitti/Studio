# Fire Escape — tool use map (Akitti 2026-09-10)

Icons: `docs/art/icons/` + `slice1/assets/icons/` (`*_256.png`)

| Tool id | Use |
|---------|-----|
| `hammer` | Break furniture → boards + nails |
| `crowbar` | Faster salvage, pry containers |
| `hand_saw` | Cut boards to size / furniture bridges |
| `hacksaw` | Cut scrap metal for the solar frame |
| `screwdriver_set` | Metal frame + screws |
| `soldering_kit` | Finish anything with copper wire (solar, lamp) |
| `wire_cutters` | Salvage wire from appliances (w/ pliers) |
| `pliers` | Salvage wire from appliances (w/ wire_cutters) |
| `adjustable_wrench` | Later pump / rail / hardware store bits |
| `utility_knife` | Open cans, cut tape, harvest twine |
| `tape_measure` | Optional flavor; or precision bonus when building bridges |
| `file` | Clean rusted parts so recipes don’t fail |
| `watering_can` | Garden water (shared can later; hands-hold water still works) |
| `bucket` | Fill / carry water (icon pending if not on sheet) |

Related salvage outputs already icon’d: `wooden_board`, `nails`, `screws`, `copper_wire`, `scrap_metal`, `solar_panel_shard`, `panel_frame`, `battery_cell`, duct/electrical tape, etc.
