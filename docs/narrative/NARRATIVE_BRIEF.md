## Premise (LOCKED)

Post-apocalyptic / semi-open-world survival set in a **cyberpunk-flavored future** that is **not** inherently dark or moody — bright-ish urban future that still has viruses and cascading failure.

Something goes wrong in (or around) an apartment tower. Chaos; people flee. The player stays and scraps together survival from balconies, scavenging, gardening, and jury-rigged devices.

Tone target: Project Zomboid systems energy × cyberpunk skin × **hopeful / scrappy** mood (not grimdark). Infected exist later; **skip monsters for Slice 0**.

- Working name: **the Intern** (name TBD).

- Starting home: a decent apartment with a **balcony** and an **engineering desk** (tools already present).
- Pronouns in pitch: she/her — treat as provisional until Akitti locks.

## Slice 0 — playable narrative space (LOCKED for first prototype)

Start **tiny**. No street open-world yet.

### Access
1. **Player balcony** — primary hub.
2. **One adjacent balcony** (left or right) — jumpable / furniture-bridge later.
3. Interior of neighbor apartment: **not** fully accessible at start.
4. Neighbor’s **glass door**: cat paws on it → player opens → **free the cat**; stay on balconies for now.

### Cat (LOCKED character beat)
- Neighbor fled; left the cat.
- Player adopts it.
- Cat uses the **fire escape** (climb up/down).
- Random beat: cat brings a **pigeon** a couple times a week (loot / food / story beat — systems TBD by Forge).

### Neighbor garden (LOCKED set dressing)
- Half-started balcony garden: **potatoes + tomatoes**.
- Player can finish / expand gardening from here.

### Player starter plants (LOCKED)
- Some **herbs** already on the player balcony.

### Fire escape / map (DIRECTION — systems)
- Long-term: fire escape → raid hardware / groceries / open world.
- Slice 0–1: **map / node travel** placeholder (not free roam). Swap to open world later.
- Hardware goal (later slice): parts for devices (e.g. solar needs **3 pieces + battery**). Battery + solar called out by Akitti as early build targets.

### Water (early systems fiction — for Forge)
- Running water works ~**first week**, then fails.
- Player should have filled containers while it lasted (sink, bathtub, pots, bottles…).
- Forces a **water collection** build beat.

### Carry / inventory fiction
- Weight in **kg**.
- Bag: starting max ~**25 kg**.
- Arms carry: extra capacity but **hands busy** (can’t use tools / interact the same way).

### Starter grocery set (example goods — not locked art)
Tomato, tuna, self-raising flour, salt, water bottles — small fixed set to prove the loop.
